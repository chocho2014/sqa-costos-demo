# Manual de usuario

1. Ejecutar npm ci, npm run build y npm start. Abrir http://127.0.0.1:3000.
2. Escribir nombre y precio positivo; Guardar agrega el producto.
3. Editar carga el registro en el formulario; Guardar confirma el cambio.
4. Eliminar borra el registro seleccionado; es una eliminación real de datos ficticios.
5. Agregar dos productos de Q10.00 y Q20.00 y un flete de Q3.00. Calcular debe mostrar Q33.00. El cálculo utiliza una unidad de cada producto del catálogo.
6. Refrescar conserva los productos porque se guardan en SQLite. Un error de API se presenta en pantalla y no se trata como éxito.

Esta aplicación demuestra el aseguramiento de calidad de una adaptación, no las pantallas operativas del ERP completo. Utilizar únicamente datos de prueba.
